# تطوير نموذج تسجيل الخريج الجديد

## التاريخ: 2025-11-27

## الهدف
تطوير نموذج تسجيل خريج جديد من خلال صفحة الترحيب لكي يتوافق مع بيانات الخريجين الموجودة لدى الإرشاد المهني.

## التغييرات المنفذة

### 1. قاعدة البيانات (Database)
- ✅ إضافة عمود `languages` إلى جدول `users`
  - الملف: `database/migrations/2025_11_27_083031_add_languages_to_users_table.php`
  - النوع: `text` (nullable)
  - الموقع: بعد عمود `skills`

### 2. النموذج (Model)
- ✅ تحديث `app/Models/User.php`
  - إضافة `languages` إلى `$fillable`
  - إضافة `languages` إلى `$casts` كـ `array`
  - الحقول الموجودة مسبقاً: `skills`, `experiences`

### 3. واجهة المستخدم (View)
- ✅ تحديث `resources/views/auth/graduate-register.blade.php`
  - إضافة قسم جديد: "المهارات والخبرات"
  - الحقول المضافة:
    1. **الخبرة العملية** (`experiences`): textarea
    2. **المهارات** (`skills`): input text (فصل بفاصلة)
    3. **اللغات** (`languages`): input text (فصل بفاصلة)

### 4. المتحكم (Controller)
- ✅ تحديث `app/Http/Controllers/GraduateRegistrationController.php`
  
  **في دالة `register()`:**
  - إضافة validation للحقول الجديدة:
    - `experiences`: nullable|string
    - `skills`: nullable|string
    - `languages`: nullable|string
  - معالجة البيانات:
    - تحويل `skills` و `languages` من نص مفصول بفواصل إلى مصفوفة
    - استخدام `array_filter` لإزالة القيم الفارغة
  - حفظ البيانات في جدول `users`

  **في دالة `approve()`:**
  - إضافة الحقول الجديدة عند إنشاء سجل في `graduates_data`:
    - `skills`: من `$user->skills`
    - `languages`: من `$user->languages`
    - `work_experience`: من `$user->experiences`

## التوافق مع جدول graduates_data

| حقل في users | حقل في graduates_data | الملاحظات |
|-------------|---------------------|-----------|
| `skills` | `skills` | مصفوفة JSON |
| `languages` | `languages` | مصفوفة JSON |
| `experiences` | `work_experience` | نص |

## طريقة الاستخدام

### للخريج الجديد:
1. الدخول إلى صفحة التسجيل: `/register/graduate`
2. ملء البيانات الشخصية والأكاديمية
3. ملء حقول المهارات والخبرات (اختيارية):
   - **الخبرة العملية**: وصف نصي للخبرات السابقة
   - **المهارات**: قائمة مفصولة بفواصل (مثال: برمجة، تصميم، إدارة)
   - **اللغات**: قائمة مفصولة بفواصل (مثال: العربية، الإنجليزية)
4. إرسال الطلب

### لمسؤول الإرشاد المهني:
1. مراجعة الطلبات في: `/career-guidance/pending-approvals`
2. عند الموافقة على الطلب:
   - يتم تفعيل حساب الخريج
   - يتم إنشاء سجل تلقائي في `graduates_data` يتضمن:
     - جميع البيانات الأكاديمية
     - المهارات واللغات كمصفوفات JSON
     - الخبرة العملية كنص

## ملاحظات تقنية
- الحقول الثلاثة اختيارية (nullable)
- يتم تحويل النص المفصول بفواصل إلى مصفوفة تلقائياً
- Laravel يقوم بتحويل المصفوفة إلى JSON عند الحفظ (بسبب array casting)
- عند القراءة، يتم تحويل JSON إلى مصفوفة تلقائياً
